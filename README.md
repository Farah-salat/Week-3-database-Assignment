# SQL Database Assignment

## Overview

This assignment provides practice with SQL statements for creating tables, inserting records, and updating data.

The assignment focuses on working with a `student` table and managing student information using SQL.

## Assignment Questions

### Question 1: Create the Student Table

A table named `student` is created with the following columns:

* `id` – Integer and primary key
* `fullName` – Text field with a maximum of 100 characters
* `age` – Integer

### Question 2: Insert Records

At least three student records are inserted into the `student` table.

### Question 3: Update Student Information

The age of the student with ID `2` is updated to `20`.

## SQL Concepts Practiced

* `CREATE TABLE`
* `INSERT INTO`
* `UPDATE`
* Primary keys
* Data types
* `WHERE` clauses
